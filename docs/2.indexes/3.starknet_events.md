## Fetching block headers

Several optional fields of `StarknetEventData` model (`timestamp`, `transaction_idx`) require additional calls to Starknet node to be filled. This is disabled by default to save RPC calls. If you need these fields, you can enable block headers fetching in the datasource configuration:

```yaml [dipdup.yaml]
datasources:
  node:
    ...
    fetch_block_headers: True
```
