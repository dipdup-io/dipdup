# Coinbase

A connector for [Coinbase Exchange API](https://docs.cdp.coinbase.com/exchange/introduction/welcome). Provides the `get_candles` method. It may be useful in enriching indexes of DeFi contracts with off-chain data.

```yaml [dipdup.yaml]
datasources:
  coinbase:
    kind: coinbase
```

Candles come from a public endpoint, so no API key is needed. Coinbase limits public endpoints to 10 requests per second per IP; the datasource stays within this limit by default. The `api_key`, `secret_key` and `passphrase` fields are accepted but not used.

The `get_oracle_prices` method raises `UnsupportedFeatureError`, since Coinbase [deprecated](https://docs.cdp.coinbase.com/exchange/changes/changelog) its Price Oracle API on 2025-01-01.
